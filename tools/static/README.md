# tools/static

Files here are copied unchanged into `public/` by `tools/build.sh`, so each is served at
`https://johnfisher-ai.github.io/Python-Visual-Guides/<file name>` and survives every build.

The Google Search Console verification file for the URL-prefix property
`https://johnfisher-ai.github.io/Python-Visual-Guides/` lives here. Never delete or rename it: Search
Console checks it again from time to time, and the property loses its verification when the file is gone.

This README is not copied.
