The guidesRepository

Learn Python by running it. Every guide is a set of notebooks that open in Google Colab: read a little, run a cell, change it, run it again. Nothing to install and nothing to set up.

New to Python? Start with Python from the Start. The guides below are in reading order.

How a notebook works. A notebook opens in Google Colab and runs in your browser. It contains the explanation, worked examples you can edit, exercises to try, and a section on the errors that part of Python actually produces, with the real message shown.

The exercises are the point. Every notebook has a separate solutions file, so the answer is never sitting one scroll below the question.

The guides

Foundations teaches the language itself, and is best worked through in order: each guide depends on the one before it. The deep dives take one library apiece, grouped by what the library is for, and any of them can be read once you have the foundations it names. Projects puts everything to work on real problems.
